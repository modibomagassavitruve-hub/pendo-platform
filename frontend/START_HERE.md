# 🚀 COMMENCEZ ICI - PENDO

## ⚠️ PROBLÈME ACTUEL

Lovable n'affiche pas vos outils car il utilise **son propre code** (non synchronisé avec GitHub).

## ✅ SOLUTION

Utilisez **Vercel** au lieu de Lovable.

### Pourquoi Vercel?

- ✅ Synchronisé automatiquement avec GitHub
- ✅ TOUS vos outils sont déjà là
- ✅ Gratuit
- ✅ Déploiement en 5 minutes

## 🎯 DÉPLOYER SUR VERCEL (5 MIN)

### 1. Créer un compte

https://vercel.com → Sign Up → Continue with GitHub

### 2. Importer le projet

Add New Project → `pendo-frontend` → Import

### 3. Variables d'environnement

```
REACT_APP_API_URL=https://pendo-backend.onrender.com/api
REACT_APP_ENV=production
REACT_APP_NAME=PENDO
REACT_APP_VERSION=1.0.0
```

### 4. Déployer

Cliquer "Deploy" → Attendre 2-3 min → ✅ TERMINÉ!
